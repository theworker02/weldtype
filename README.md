# weldtype

Weld HTML/Markdown type fragments safely for docs pipelines.

**Site:** https://theworker02.github.io/weldtype/

## Install / run

```bash
git clone https://github.com/theworker02/weldtype.git
cd weldtype
node src/cli.js
node --test
```
